# Android Auto Maker (Code will follow)

Android Auto Maker prepares an APK or XAPK so the app can show on Android Auto while the car is parked. An XAPK is turned into one APK. You can save that APK or install it on the phone.

A parked game needs a phone on Android 15 or newer. Uninstall the original app before you install the result. The prepared app is signed again, so Android treats it as a different copy of the same package.

## Website (Code will follow)

The website runs on a computer. Open the address it prints, from that computer or from another device on the same network.

1. Choose an `.apk` or `.xapk` file, or drop it on the page.
2. Leave **Parked game** selected. The app is available while the car is parked.
3. Press **Create Android Auto package** and wait until it finishes.
4. Press **Download APK** to save the file, or **Install on phone** to install it from this computer.

Install on phone needs the phone connected to the computer, with USB debugging on, and this computer accepted on the phone. Stay on the page until it says the app was installed. The download stays available after that.

## Android app

Install Android Auto Maker on the phone, then open it.

1. Press **Choose an APK or XAPK** and select the file.
2. Leave **Parked game** selected.
3. Press **Create Android Auto package** and wait until it finishes.
4. Press **Save** to keep the APK, or **Install** to install it on this phone.

If Android asks for permission to install unknown apps, allow it for Android Auto Maker and try Install again. Complete the installer on the phone. The screen stays on Installing until the package is on the phone, or until it reports that the app was not installed.
