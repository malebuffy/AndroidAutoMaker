02 // BRIEFING

Uninstall the original app first. A parked game needs a phone on Android 15 or newer.

Navigation needs Shizuku or root (phone only)

Shizuku is a helper app that gives the patched app permission to run system commands that Android normally blocks. A rooted phone can do the same without Shizuku. The patched app uses it to place its own screen on the car display. Install Shizuku on the phone only. Nothing is installed on the car.

  1. Install the Shizuku app (moe.shizuku.privileged.api) on the phone. Get it from Google Play, GitHub releases, or shizuku.rikka.app/download. Setup guide: shizuku.rikka.app/guide/setup.
  2. Start Shizuku with Wireless Debugging or ADB, then leave it running. Skip this if the phone is rooted.
  3. Install the Navigation package from this page, open it in Android Auto, and tap Allow if it asks for Shizuku.
  4. If the car screen stays on the icon, Shizuku is stopped, root is unavailable, or permission was denied.

Parked games do not need Shizuku.
